# Agent Instructions

## Project
- This is an iOS SwiftUI app package intended to run in Swift Playgrounds on iPad.
- Follow the existing Swift and SwiftUI patterns in the project and keep changes focused.
- `Package.swift` is generated by Swift Playgrounds. Do not edit it by hand unless explicitly requested.

## Changes and Verification
- When changing Swift source, tell the user which files to replace in Swift Playgrounds and whether the app's backend server needs restarting.
- Prefer validating app behavior in Swift Playgrounds on iPad. A Linux `swift build` may fail because `AppleProductTypes` is an Apple-only module; treat that as an environment limitation, not proof of a source error.
- For source-only changes, use available static checks where useful, and clearly report anything that could not be verified on this server.
- When requested project work is complete, commit the intended project changes and push them to the configured GitHub remote. Exclude generated files and unrelated user changes.
- Preserve existing user changes and avoid unrelated refactors.
